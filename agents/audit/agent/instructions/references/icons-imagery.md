# Icons and imagery

- Use Hugeicons as the default icon set. Install only the icons an app needs, one file per icon.
- Bundle icons locally. Do not load them from an API.
- Pull every logo and mark from one assets source.
- Provide separate light and dark logo variants. Use real client logos.
- Color SVG icons with `currentColor` or CSS variables, so states can recolor them.
- Keep icon markup simple. No wrapper boxes; use a larger icon instead.
- Update OG images and favicons whenever the logo changes.
- Use real HTML text for wordmarks and labels, not text converted to shapes.
- Use real client logos from Brandfetch. Do not use white logos on light backgrounds; use dark logo versions. (White logos were invisible on light cards.)
