# UI copy

- Copy explains what is happening and why someone should care. Define vague words. Show the benefit at each step.
- Use plain words a client would use. No AI-sounding phrases or internal jargon.
- Use short, simple labels ("Requests", "Changes"). Keep notice text simple.
- Remove lists and details that repeat what is already shown.
- No placeholder names or editorial notes in shipped content.
- Use personal, action-oriented CTAs ("Talk to <name>").
- Write READMEs and docs in a plain, direct voice.
- Name metrics with the shared field terms from the locale file, not new labels. (One shared glossary keeps metric names the same on every screen.)
- Use short, plain words in notice text and headings. (The columns notice language was too complex.)
- Use plain labels a client would say, not AI-sounding phrases like 'Keep the new Answer'. (AI-sounding wording feels unnatural to partners.)
- Name UI concepts by the action the user takes, not by a container word like 'Cards'. (Partners do not understand 'Cards'. An ask is an action.)
- Keep header labels short so they never truncate. For example, use "AI Assistant". (A long header label was cut off on screen.)
